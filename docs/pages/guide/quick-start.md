# Installation Guide

Follow these steps to install Flint in your project.

## Step 1: Choose Your Package Manager
Flint is available through various package managers. Choose the one that fits your project:

### npm
```bash
npm install --save-dev @capsulescodes/flint
```

### yarn
```bash
yarn add --dev @capsulescodes/flint
```

### pnpm
```bash
pnpm add --save-dev @capsulescodes/flint
```

## Step 2: Initialize Flint
After installation, initialize Flint:
```bash
npx flint --init
```

This will create a `.flint` directory and a `flint.config.json` file in your project.
