# What is Flint?

Flint empowers developers to write code their way while ensuring remote consistency. By integrating with Git, Flint automatically formats code during `pull` and `push` operations, preventing commits from being cluttered with formatting changes.

## Key Features
- **Personal Style**: Use your own formatting preferences locally.
- **Remote Consistency**: Maintain a consistent codebase across all contributions.
- **Cleaner Commits**: Keep formatting changes separate from logic changes.
